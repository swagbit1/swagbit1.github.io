The problem

A voice-ordering interface needs to turn customer requests into an order the kitchen can follow as it changes.

My contribution

Built the Node.js and React foundation and Express/ElevenLabs integration, then used Socket.IO to synchronize orders. This was a team project; computer vision and all kitchen-screen work are not claimed as individual contributions.

Engineering decisions

Server-side integration

Express mediates requests to ElevenLabs so provider credentials are not exposed in the browser.

Shared order updates
